# BloodCell - Adversarial Robustness and Explainability of CNNs for Blood Cells

## Project goal

Train two CNN classifiers (**ResNet-18** and fine-tuned **MobileNetV2**) to classify blood cells into 8 classes (BloodMNIST), evaluate their vulnerability to adversarial attacks (**FGSM** and **PGD**), apply **Adversarial Training** to obtain "hardened" versions of the models (hardened ResNet-18 and **MobileNetV2 "KevlarNet"**), and analyze the explainability of their decisions via **Grad-CAM** and **Integrated Gradients**, with an applied focus on clinical relevance for **beta-thalassemia** diagnosis.

## Research questions

- How much does model accuracy (ResNet-18, MobileNetV2) degrade under FGSM and PGD adversarial attacks as perturbation intensity (ε) increases, and which architecture proves more robust "out of the box"?
- Can Adversarial Training (fine-tuning on adversarial examples) "harden" the models — hardened ResNet and MobileNetV2 KevlarNet — while keeping a good trade-off between clean-data accuracy and robustness to perturbations?
- Does the model base its decisions on clinically relevant morphological structures (nucleus, chromatin, cytoplasmic granularity) or on statistical artifacts of the dataset? How does this focus, measured with Grad-CAM and Integrated Gradients, change before and after Adversarial Training?
- Which cell classes — in particular Erythroblast and Immature Granulocyte, both relevant for monitoring beta-thalassemia — are most vulnerable to adversarial attacks?

## Dataset

- Source: [MedMNIST - BloodMNIST](https://medmnist.com/)
- Images resized to 224×224 (upscaled from the original 28×28) for use with ImageNet-pretrained architectures (ResNet-18, MobileNetV2)
- Normalized with ImageNet mean/std (`[0.485, 0.456, 0.406]` / `[0.229, 0.224, 0.225]`)
- Classes (8): Basophil, Eosinophil, Erythroblast, Immature Granulocytes, Lymphocyte, Monocyte, Neutrophil, Platelet
- Automatic download handled by the `medmnist` library inside the notebooks (no raw data versioned in the repository)

## Required libraries

See `requirements.txt`. Main ones: `torch`, `torchvision`, `medmnist`, `torchcam`, `grad-cam`, `opencv-python`, `Pillow`, `scikit-learn`, `seaborn`, `matplotlib`, `numpy`, `tqdm`.

**Note:** unlike the DL project (based on TensorFlow/Keras), this project is entirely developed in **PyTorch/torchvision**, given the use of ImageNet-pretrained models (ResNet-18, MobileNetV2) and explainability libraries (`torchcam`, `grad-cam`) native to the PyTorch ecosystem.

## Why this framework

The project uses **PyTorch** as the main framework for:

- direct access to gradients with respect to the input, needed to implement the FGSM and PGD adversarial attacks "by hand" and for Adversarial Training;
- the wide availability of pretrained architectures (`torchvision.models`) and mature explainability libraries (Grad-CAM, Integrated Gradients) in the PyTorch ecosystem;
- fine-grained control over the training loop, useful for alternating epochs on clean data and adversarial examples during Adversarial Fine-Tuning.

Installation instructions are in `requirements.txt` (`pip install -r requirements.txt`).

## Notebook execution order

1. `notebooks/BloodMNIST - ResNet18.ipynb` — downloads BloodMNIST, trains ResNet-18 (hyperparameter grid search), FGSM/PGD attacks, ε curves, Grad-CAM.
2. `notebooks/BloodMNIST - ResNet_Hardened.ipynb` — starts from the base ResNet-18, applies Adversarial Fine-Tuning, evaluates the robustness of the "hardened" model and its explainability (Grad-CAM, Integrated Gradients).
3. `notebooks/BloodMNIST - MobileNetV2.ipynb` — trains MobileNetV2 (grid search), FGSM/PGD attacks, ε curves, Grad-CAM, PEAS analysis and beta-thalassemia clinical context.
4. `notebooks/BloodMNIST - MobileNetV2_Hardened.ipynb` — Adversarial Fine-Tuning of MobileNetV2 to obtain **KevlarNet** ("as light as a MobileNet, as tough as a bulletproof vest"), robustness evaluation and Grad-CAM.
5. `notebooks/BloodMNIST - Comparison.ipynb` — loads all models saved under `models/` and compares the architectures on: complexity, clean accuracy, adversarial robustness, classes critical for beta-thalassemia, Grad-CAM explainability, final summary table.

## Technical notes

- **Adversarial attacks:** FGSM (one-step perturbation in the gradient direction) and PGD (iterative version projected into the ε-ball), with grid search over step size (`alpha`) and number of steps.
- **Adversarial Training:** fine-tuning of the base models by including adversarial examples generated "on the fly" in the training loop, to increase robustness without changing the architecture.
- **Explainability:** Grad-CAM (Selvaraju et al., 2017) and Integrated Gradients to visualize/quantify which image regions (nucleus, cytoplasm vs. background) the predictions rely on, before and after Adversarial Training.
- **Clinical context:** particular attention to the Erythroblast and Immature Granulocyte classes (indicators of ineffective erythropoiesis/marrow response in beta-thalassemia) and Platelet (thrombocytopenia from hypersplenism).
- **Relative paths:** the notebooks reference the `models/` and `images/` folders with relative paths (`../Modelli`, `../Immagini` in some cells): check/align the working directory or folder names (case-sensitive on Linux/GitHub) before re-running from scratch.
